# PhotoAtlas

PhotoAtlas — локальное приложение для просмотра фотографий на карте по GPS-координатам из EXIF.

## Идея

Пользователь выбирает папку с фотографиями. Программа читает координаты съёмки из EXIF и красиво отображает снимки на карте.

## Основные принципы

- Локальная обработка данных.
- Без обязательного облака.
- Красивый плавный интерфейс.
- Кластеризация близких фотографий.
- Кроссплатформенность в перспективе.

## Планируемый стек

- Tauri 2
- Rust
- React
- TypeScript
- Vite
- MapLibre GL JS
- SQLite
